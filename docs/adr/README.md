# Architecture decision records

This directory records durable implementation decisions that have credible
alternatives and affect compatibility, data, runtime behavior, or component
boundaries.

Operational workflow and release policy belong in their authoritative project
documentation. Commands, field formats, test evidence, benchmark results, and
migration steps should also remain with the documents that define them.
